# 아키텍처 결정 기록 (ADR)

새로운 아키텍처 결정 시 아래 템플릿으로 기록합니다.

## 템플릿

### ADR-NNN: [제목]
- **날짜**: YYYY-MM-DD
- **상태**: 제안됨 | 수락됨 | 폐기됨
- **맥락**: 결정이 필요한 배경
- **결정**: 무엇을 하기로 했는가
- **근거**: 왜 이 결정을 했는가
- **결과**: 어떤 영향이 있는가
