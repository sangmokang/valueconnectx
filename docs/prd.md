# ValueConnect X — Public Product Brief

> 대외 공표용 제품 소개. 내부 운영·보안·재무·구현 디테일은 의도적으로 제외되었습니다.
> 작성일: 2026-04-28 · 문서 버전: Public v1.0

---

## 1. 한 줄 정의

ValueConnect X 는 **검증된 핵심 인재와 기업 리더를 연결하는 초대 전용(Invite-only) Private Talent Network** 입니다.

회사에 한 명 있을까 말까 한 사람들이 서로를 알아보고, 성장하고, 커리어의 다음 챕터를 자신의 방식으로 써내려가는 비공개 네트워크를 지향합니다.

---

## 2. 누구를 위한 서비스인가

| 대상 | 가치 |
|---|---|
| **시대의 핵심 인재** (시니어 IC · 리더 · 도메인 전문가) | 검증된 동료들과의 사적 라운지, 양질의 채용 시장 시그널, 자신의 속도로 다음 기회를 탐색할 권리 |
| **기업 리더** (CEO · Founder · C-Level · HR Leader) | 기존 채널로는 닿지 않는 인재 풀, 직접 대화 기반 채용 연결, 양방향 신뢰가 형성된 후의 만남 |

전제: **아무나 들어올 수 없는 네트워크.** 마찰은 의도된 신호입니다.

---

## 3. 제품 구조 — 3 레이어

ValueConnect X 는 단일 기능이 아닌 **세 개의 레이어가 서로를 강화**하도록 설계됐습니다.

| 레이어 | 역할 | 사용자 가치 |
|---|---|---|
| ① **채용시장 큐레이션 피드** (Hook) | 관심 분야 기반 채용 시장 시그널을 정기적으로 전달 | 네트워크에 참여하지 않아도 즉시 개인적 가치 발생 |
| ② **커뮤니티 라운지** (Sticky) | 익명 글쓰기 기반 비공개 라운지 | 솔직한 대화 · 동료 발견 · 머무는 이유 |
| ③ **커피챗 기반 연결** (Connect) | Peer · CEO 두 갈래의 1:1 대화 채널 | 면접 이전의 상호 탐색 — 양방향 선택권 |

세 레이어는 분리 운영됩니다. **커뮤니티 라운지의 글은 채용 활용이 불가**하며, 시스템 차원에서 분리됩니다.

---

## 4. 핵심 기능

### 4.1 채용시장 큐레이션 피드
- 멤버가 자유 입력 태그로 관심 시장을 표현 (예: "딥테크 백엔드", "Series A 스타트업")
- 큐레이션된 채용 시그널을 인앱 피드 + 정기 뉴스레터로 전달
- 멤버는 "관심 있음 / 관심 없음" 으로 큐레이션 품질에 직접 기여

### 4.2 커뮤니티 라운지
- **익명 글쓰기** — 멤버 자격은 인증되지만 이름은 노출되지 않음
- **카테고리** — 독서·인사이트, 이직 이야기, 회사 생활, 리더십·조직, 생산성·Tech, 가벼운 이야기
- **Privacy Rule** — 라운지 게시물은 채용 의사결정에 활용되지 않음 (시스템 격리)
- **모더레이션** — 운영팀 삭제 권한, 멤버 신고, 반복 위반 시 작성 제한

### 4.3 Member Directory
- 검증된 멤버만 모인 디렉토리 — 직군 · 전문 분야 · 산업 기준 탐색
- LinkedIn 연동을 통한 신뢰 검증 (자동 스크래핑 아님 — 본인 입력)
- Anti-Scraping 보호 (외부 자동 수집 차단)
- Member Tier 배지 노출 (Core / Endorsed)

### 4.4 Position Board
- ValueConnect X 가 큐레이션하여 등록한 포지션만 노출
- 멤버는 "관심 있음 / 관심 없음 / 나중에 보기" 3 가지 액션
- 기업이 임의로 포스팅하는 일반 채용공고 게시판이 아닙니다

### 4.5 Peer Coffee Chat
- 멤버가 사연·테마를 올리고 신청자를 직접 선택
- 동료의 시간을 빌리는 행위에 대한 상호 합의 기반

### 4.6 CEO Coffee Chat
- 기업 리더(CEO·Founder·C-Level)가 세션을 열고, 멤버가 신청, 리더가 선택
- 면접이 아닌 **초대장** — 역방향 채용의 무게감을 의도적으로 디자인

---

## 5. 디자인 철학 — Quiet Luxury

ValueConnect X 의 인터페이스는 절제된 에디토리얼 미학을 따릅니다.

| 원칙 | 적용 방식 |
|---|---|
| 뿌리지 않는다 | 정보 밀도를 낮게. 화면당 하나의 핵심 메시지. |
| 신뢰가 먼저 | 화려한 기능보다 텍스트와 여백으로 무게감 전달 |
| 인재 정체성 강화 | "지원" 이 아닌 "연결", "선택" 이 아닌 "기회" |
| 마찰은 의도적으로 | 아무나 들어올 수 없다는 신호 — 초대 코드, 승인 단계 |

비주얼 톤: 크림 · 니어 블랙 · 골드 액센트 · 세리프 디스플레이 + 산세리프 본문. 모바일 우선 (Galaxy 기준 360px 까지 대응).

---

## 6. 신뢰 & 프라이버시 약속

ValueConnect X 가 멤버에게 약속하는 원칙:

1. **초대 전용** — 네트워크의 품질은 입구에서 결정됩니다. 공개 회원가입은 제공되지 않습니다.
2. **데이터 분리** — 커뮤니티 라운지의 글은 채용 의사결정에 사용되지 않습니다.
3. **자동 수집 금지** — 멤버 디렉토리는 외부 자동 수집(스크래핑)으로부터 보호됩니다.
4. **명시적 동의** — 채용 연결로 이어지는 행위(커피챗 신청·수락)는 멤버의 명시적 의사 표시에 한정됩니다.
5. **익명성 보장** — 라운지 글의 익명성은 시스템 차원에서 보장됩니다.
6. **개인정보 보호** — 한국 PIPA(개인정보 보호법) 기준 처리방침을 준수합니다.

## 7. 로드맵

ValueConnect X 는 단계별로 다음 가치를 차곡차곡 쌓아갑니다.

### Phase 1 — Foundation
- 초대 전용 가입 흐름 · 이메일 기반 보안 로그인
- Member Profile & Directory
- 큐레이션된 Position Board
- 채용시장 뉴스레터 (정기 발송)
- 커뮤니티 라운지 오픈
- 모바일 우선 UX 정착

### Phase 2 — Engagement & Connection
- Peer Coffee Chat 정식 런칭
- CEO Coffee Chat 정식 런칭
- 큐레이션 자동화 — 관심 분야 태그 기반 개인화 강화
- 라운지 모더레이션 정교화

### Phase 3 — Scale
- 자연어 기반 시장 구독 인터페이스
- 매칭 시그널 고도화
- 본인 인증 채널 다양화
- 글로벌 한국인 인재 네트워크 확장

> 단계 간 전환은 사용자 가치와 네트워크 건강성 지표가 충족될 때만 진행하며, 외형적 성장만을 위한 가속은 의도적으로 피합니다.

---

## 8. 우리가 하지 않는 것

서비스 정체성을 지키기 위해 의도적으로 **하지 않는 것** 들이 있습니다.

| 영역 | 입장 |
|---|---|
| 공개 회원가입 | 제공하지 않음 — 초대 전용 유지 |
| 외부 프로필 자동 수집 | 시도하지 않음 — 본인 입력만 |
| 강제된 콘텐츠 유도 | 인위적 활동 부풀리기를 지양 — 자연스러운 참여를 지향합니다 |
| 일반 구인구직 게시판화 | 기업 셀프 포스팅 미허용 — 큐레이션만 |
| 라운지 발언의 채용 활용 | 절대 불가 — 데이터 격리 |
| 화려한 게이미피케이션 | 신뢰 기반 서비스에 부합하지 않음 |

---

## 9. 한 줄 요약

> 채용시장 큐레이션으로 유입하고, 커뮤니티 라운지로 머물게 하며, 커피챗으로 다음 챕터를 연결한다.
>
> 가장 중요한 것은 빠르게 많이 모으는 것이 아니라, 모인 사람들이 머물 이유를 설계하는 것이다.
