## 1. 한 줄 요약

> **초대받은 인재가 자신의 관심 기반으로 시장을 읽고, 동료와 결을 확인하고, 함께 일할 사람을 직접 만나는 사적인 네트워크가 열렸습니다.**

ValueConnect X는 헤드헌팅 사이트도, 일반 채용 플랫폼도 아닙니다. **초대받은 사람들만의 Private Network**입니다.

---

## 2. 이번 릴리즈에서 만나는 6가지 경험

ValueConnect X는 6개의 기둥(Pillar)으로 설계되었습니다. 각 기둥은 독립적으로도 가치 있고, 함께 작동할 때 더 큰 의미를 만듭니다.

### 01. 큐레이션 피드 — 시장을 읽는 가장 빠른 방법

관심 분야를 등록하면, 그 시장의 동향과 핵심 기회가 매주 도착합니다.
- 자유 태그로 관심 영역을 표현 (최대 5개)
- 큐레이터가 직접 선별한 시장 신호와 기회
- 인앱 피드 + 주 1회 뉴스레터

> Phase 1에서는 큐레이터가 직접 선별합니다. 자동화는 Phase 2에서 단계적으로 도입됩니다.

### 02. 커뮤니티 라운지 — 익명이 만드는 솔직한 공간

초대 전용 익명 커뮤니티. 실명으로는 꺼내기 어려운 이야기들이 모입니다.
- 6개 카테고리: 독서·인사이트, 이직 이야기, 회사 생활, 리더십·조직, 생산성·Tech, 가벼운 대화
- 닉네임 또는 익명으로 작성
- 이모지 반응, 인라인 확장 보기
- 멤버 신고 + 어드민 모더레이션 운영

> 커뮤니티 글은 채용 활용에 사용되지 않습니다. 시스템 차원에서 분리되어 있습니다.

### 03. CEO 커피챗 — 서로의 결을 확인하는 자리

공개 정보로는 알 수 없는 것들 — 조직의 언어, 리더십의 결, 일하는 방식.
- C-level과 1:1로 직접 대화
- **AI Brief**: 미팅 전 양측 맥락을 정리한 사전 브리핑 카드
- 세션 후 피드백 (전반 평가, 컬쳐핏, 다시 연결 의향)

### 04. 멤버 커피챗 — 같은 고도의 대화

멤버가 사연을 올리고, 신청자를 직접 선택하는 P2P 네트워킹.
- 자기 사연 게시 → 신청자 검토 → 본인이 선택
- 편집/재신청 플로우
- 가까운 지인보다 다른 맥락의 멤버와 만나는 느슨한 연결

### 05. 멤버 디렉토리 — 검증된 동료들의 풍경

이름, 직군, 전문 분야로 멤버를 탐색합니다.
- Core / Endorsed 두 등급으로 신뢰도 표시
- 프로필 공개·비공개 플래그 멤버가 직접 제어
- 검색 결과는 본인이 허용한 범위 안에서만 표시됩니다

### 06. AI Brief 시스템 — 미팅의 밀도를 높이는 AI 레이어

커피챗이 수락되는 순간, AI가 양측 프로필과 사연을 읽고 사전 브리핑을 생성합니다.
- 미팅 전 PreBriefCard로 노출
- 모바일(Galaxy 360px 폭) 포함 반응형
- API 키 미설정 시 안전한 fallback UI 제공

## 3. 멤버 온보딩 흐름이 이렇게 바뀌었습니다

Phase 0 대비 가장 크게 다듬어진 곳은 **첫 진입 경험**입니다.

| 변경 영역 | 변경 전 | 변경 후 (Phase 1) |
|---|---|---|
| 초대 수락 → 온보딩 진입 | GNB가 노출되어 무한 리다이렉트 발생 | `/onboarding`에서 GNB 숨김 처리, 안정적 진입 |
| 이름·LinkedIn 입력 | 초대 수락에서 받은 정보를 다시 묻던 중복 폼 | 받은 값 pre-fill, 한 번만 입력 |
| 전문 분야 선택 | 영문/한글 라벨 혼재 | 자유 태그(한국어) 입력으로 전환 |
| 진행률 표시 | 항상 0%에서 시작 | 기입력 데이터를 반영해 정확히 시작 |
| 폼 단계 | 단일 거대 폼 | 2단계(필수→선택) 분리 + 진행률 바 |

> 닉네임 필드가 추가되어, 디렉토리·커뮤니티에서 표시되는 이름을 멤버가 직접 결정합니다.

## 4. 디자인·접근성 가이드라인

이번 릴리즈는 **유지보수 가능한 안정성**을 우선했습니다.

- 전역 `border-radius: 0` 정책 유지 (각진 시각 언어)
- 디자인 토큰: 배경 `#f5f0e8`, 강조 골드 `#c9a84c`, 본문 `#555`
- 본문 한글 서체: Noto Serif KR + Pretendard
- 모바일 우선 반응형(Galaxy 360px 폭에서 시작)
- 모든 UI 텍스트는 한국어, 사용자 노출 에러 메시지 또한 한국어

## 5. 알려진 제한 사항 (Phase 1 시점)

투명하게 공유합니다. 아래 항목들은 Phase 2에서 다뤄집니다.

| 영역 | 제한 사항 | 다음 단계 |
|---|---|---|
| 큐레이션 피드 | 큐레이터 수동 선별 (자동화 미구현) | Phase 2 자동 파이프라인 + 자연어 구독 |
| 뉴스레터 | 첫 회 발송 + 오픈/클릭 측정 단계 | 정기 리듬 확립 후 Phase 2에서 개인화 |
| 알림 | 인앱 위주, 외부 채널 알림 최소 | Phase 2에서 채널 확장 검토 |
| AI Brief | 단일 모델·단일 프롬프트로 운영 | Phase 2에서 V2(맥락 다층화) 검토 |
| 디렉토리 검색 | 키워드·태그 기반 | Phase 2에서 시맨틱 검색 검토 |
| 프로필 공개 플래그 | 멤버가 직접 토글, 일부 페이지 표시 정합성 재검증 진행 중 | Sprint 후속에서 마무리 |

## 6. 멤버에게 드리는 부탁

- **솔직함이 신뢰를 만듭니다.** 커뮤니티에서 익명으로 남기는 한 마디가, 누군가의 다음 결정을 바꿉니다.
- **피드백은 곧 다음 버전입니다.** 커피챗 후 남기는 피드백은 제품의 다음 모양을 결정합니다.
- **초대는 곧 책임입니다.** 동료를 초대하실 때, 이 공간이 어떤 곳인지 한 번 더 떠올려 주십시오.
