## TC-01 로그인 후 첫 화면 = 멤버 디렉토리

### 배경

- `sanitizeRedirect(redirectTo, fallback = '/directory')` — 로그인 폼 기본 리다이렉트는 `/directory`로 설정되어 있음 (`src/lib/auth/routes.ts:28`)
- 서비스 소개(`/`)는 public 라우트이므로 로그인 여부와 무관하게 진입 가능
- 스크린샷(Image #3)에서 로그인 후 서비스 소개 화면이 표시되고 있음 → 리다이렉트 미작동 가능성

### 기대 동작

1. 미로그인 상태에서 `/login` 접속 → 로그인 완료 → **`/directory`로 이동**
2. 미로그인 상태에서 protected 경로(`/feed`, `/directory` 등) 직접 접속 → 로그인 후 **해당 경로로 복귀**
3. 서비스 소개(`/`)는 로그인 여부와 무관하게 진입 가능하되, **GNB의 "멤버 디렉토리" 링크가 최상단에 명확히 노출**되어야 함

### 테스트 케이스

| ID | 시나리오 | 입력 | 기대 결과 | 합격 기준 |
|----|----------|------|-----------|-----------|
| TC-01-A | 직접 로그인 | `/login` → 로그인 성공 | `/directory` 화면 표시 | URL = `/directory`, 멤버 카드 그리드 렌더링 |
| TC-01-B | 리다이렉트 보존 | `/feed`로 직접 접근 → 로그인 팝업 → 로그인 성공 | `/feed` 화면 표시 | URL = `/feed` |
| TC-01-C | 서비스 소개 접근 | 로그인 후 `/` 접속 | 서비스 소개 표시 (정상) | 서비스 소개 페이지 표시, GNB에 "멤버 디렉토리" 링크 존재 |

## TC-02 큐레이션 피드 — AI 실데이터 구동 (콜드 스타트 해소)

### 배경

현재 피드(`/api/feed`)는 DB에 수동으로 시딩된 포지션 데이터를 반환합니다. 신규 서비스 오픈 시점에 데이터가 없으면 빈 피드 화면이 노출되어 사용자 이탈이 발생합니다(콜드 스타트 문제).

**목표**: AI가 외부 소스에서 주제별 뉴스/신호를 자동으로 수집·요약하여 피드에 실데이터를 상시 공급.

### 수집 대상 소스

| 소스 | 유형 | 한국 시장 필터 |
|------|------|----------------|
| Reddit (r/startups, r/tech, r/korea, r/MachineLearning 등) | 커뮤니티 토론 | KR 기업 언급, 아시아 VC 라운드 |
| X.com (구 Twitter) | 실시간 트렌드 | 국내 테크 리더 계정, #KRtech |
| TechCrunch | 테크 미디어 | 한국 스타트업 투자 기사, 글로벌→KR 파급 분석 |
| The Information / Bloomberg Tech | 심층 분석 | 국내 대기업(삼성·현대·카카오·네이버 등) 전략 관련 |
| 벤처스퀘어 / 한국경제 IT | 국내 미디어 | 직접 KR 시장 신호 |

### 관심 분야 태그 (Interest Selector, Image #1 기준)

피드 AI는 아래 태그를 기준으로 기사를 분류하여 사용자 선택 태그와 매칭합니다.

```
딥테크 | 핀테크 B2B | AI·머신러닝 | 시리즈 A 스타트업
엔터프라이즈 소프트웨어 | 모빌리티 | 헬스케어·바이오
컨슈머 앱 | 콘텐츠·미디어 | 클라우드 인프라
```

### AI 큐레이션 파이프라인 요구사항

```
[스케줄러 - 매주 월요일 08:00 KST]
  └─ 소스 크롤러 (Reddit RSS / X API / TC RSS / 국내 미디어 RSS)
       └─ Claude API 요약·태깅
            ├─ 한국 시장 관련성 점수 (0~1)
            ├─ 관심 분야 태그 자동 분류
            └─ 요약 텍스트 (3~5문장, 한국어)
  └─ vcx_feed_items 테이블 INSERT
  └─ 기존 3주 이상 아이템 archive 처리
```
