## 현재 랜딩 하단 섹션 문구

파일:
- `src/components/service-pillars.tsx`

화면 노출:
- 예. 현재 랜딩 페이지의 하단 기능 소개 영역에 노출됩니다.

### 섹션 제목

```text
다섯 가지 핵심 경험
한 번 들어오면 계속 돌아오게 만드는 구조
```

### 섹션 설명

```text
각 기능은 독립된 카드처럼 명확하지만, 사용자의 다음 행동으로 자연스럽게 이어집니다.
```

### 01 큐레이션 피드

```text
채용시장 큐레이션 피드

관심 분야를 등록하면 해당 시장의 동향과 핵심 기회가 매주 요약되어 도착합니다. 시장을 읽는 가장 빠른 방법.

설계 의도:
네트워크가 아직 작아도 개인적 가치가 즉시 발생하는 서비스를 먼저 만듭니다. 인재를 끌어오는 첫 번째 이유는 커뮤니티가 아니라, 혼자서도 가치를 느끼는 정보입니다.
```

### 02 커뮤니티 라운지

```text
커뮤니티 라운지

초대 전용 익명 커뮤니티. 익명이 솔직함을 만들고, 솔직함이 신뢰를 만든다. 이직 이야기, 리더십 고민, 연봉 협상 — 실명으로는 꺼내기 어려운 것들.

설계 의도:
커뮤니티 없이는 최고 수준의 인재가 머물지 않는다. VCX의 커뮤니티는 채용의 수단이 아닌 목적 그 자체다.
```

### 03 CEO 커피챗

```text
서로의 결을 확인하는 자리

공개 정보로는 알 수 없는 것들 — 조직의 언어, 리더십의 결, 일하는 방식. CEO와 직접 대화하며 서로의 컬쳐핏을 확인합니다.

설계 의도:
최고의 인재는 연봉이 아니라 함께 일할 사람을 보고 결정한다. CEO 커피챗은 그 판단의 밀도를 높이는 구조다.
```

### 04 멤버 커피챗

```text
같은 고도의 대화

멤버가 사연을 올리고 신청자를 직접 선택하는 P2P 네트워킹.

설계 의도:
정보 격차를 좁히는 단서는 가까운 지인보다 서로 다른 맥락을 가진 멤버와의 느슨한 연결에서 올 때가 많습니다.
```

### 05 포지션 보드

```text
큐레이션 피드

검증된 시장 신호와 핵심 기회를 관심 분야 기준으로 선별합니다. 공개 채널을 훑지 않아도 이번 주 확인할 흐름을 먼저 볼 수 있습니다.

설계 의도:
정보 과부하의 시대에 진짜 희소 자원은 '좋은 필터'다. 스펙이 아닌 결(texture)로 선별되는 포지션은 의사결정의 질을 바꾼다.
```

## 정리

현재 실제 랜딩 Hero에 노출되는 문구는 `src/app/page.tsx`의 v2 현행 문구입니다.

`docs/copy/landing.md`는 이 문구를 관리하기 위한 공식 문서입니다.

`src/constants/site.ts`, `src/lib/constants.ts`의 Hero/Closing 문구는 현재 사용처가 없어 보이므로, 정리 대상 후보입니다.
